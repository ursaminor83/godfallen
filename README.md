# 신이 죽은 자리 (Godfallen)

2D dark fantasy tactical SRPG browser prototype.

Open `index.html` locally or enable GitHub Pages (Settings > Pages > Deploy from a branch > main / root).

Controls: click a blue unit, click highlighted tile to move, click red enemy to attack; End Turn to let enemies act. Defeat all enemies to win.

This is a standalone HTML/CSS/JavaScript gameplay prototype, not a Unity project. The eventual Unity game will be a separate development project.
